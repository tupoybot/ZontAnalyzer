# ZontAnalyzer

`#for-human`

ZontAnalyzer собирает телеметрию ZONT и превращает её в понятные отчёты о работе
отопления. Приложение помогает оценить температуру, горячее водоснабжение, работу
горелки, расход газа и качество исходных данных, но не управляет котлом и не меняет
настройки ZONT.

## Возможности

- собирает историю ZONT в режиме только для чтения;
- рассчитывает дневные, недельные, месячные и сезонные показатели;
- публикует автономные HTML-отчёты, JSON и календарь завершённых периодов;
- учитывает показания счётчика и помесячные тарифы на газ;
- отделяет измеренные факты от выводов и явно показывает недостаток данных;
- при необходимости дополняет результат AI-анализом без передачи сырых временных
  рядов и без доступа модели к управлению оборудованием.

Многокомнатный анализ и управление котлом не входят в текущую версию. Telegram и
email также не используются как каналы доставки.

## Быстрый старт для разработки

Понадобятся Docker и доступ к Docker daemon. Полная локальная проверка запускается
из корня репозитория:

```sh
deploy/check-local.sh
```

Скрипт собирает тестовый образ, запускает Ruff, mypy и тесты с одноразовой локальной
YDB, затем проверяет сборку пакета. Ключи ZONT и OpenAI для этого не нужны. Исходный
код подключается к контейнерам только для чтения, а зависимости не устанавливаются
в Python основной системы.

Подробные требования и отдельные команды приведены в
[инструкции по контейнерной разработке](docs/development/container-development.md).

## Настройка и запуск

Пример несекретных настроек находится в [`config.example.yaml`](config.example.yaml).
Адрес YDB, имя базы и учётные данные передаются через частное окружение. Токены и
другие секреты нельзя добавлять в конфигурацию репозитория.

После настройки основные действия доступны через `zont-analyzer`:

```sh
zont-analyzer init
zont-analyzer doctor
zont-analyzer sync --backfill 90d
zont-analyzer analyze daily --date YYYY-MM-DD --no-ai
zont-analyzer report publish
```

`init` создаёт схему YDB, `doctor` проверяет конфигурацию, `sync` загружает
телеметрию, а две последние команды рассчитывают и публикуют отчёт. Полный список
команд и параметров показывает `zont-analyzer --help`. Проверка реального доступа к
ZONT выполняется отдельно командой `zont-analyzer doctor --live`.

## Безопасность и ограничения

Интеграция с ZONT использует только операции чтения. Рекомендации приложения — это
предложения для ручной проверки, а не команды оборудованию. AI необязателен: без него
доступны сбор данных, расчёты и публикация отчётов. Не используйте синтетические
данные как подтверждение корректности анализа реальной системы отопления.
