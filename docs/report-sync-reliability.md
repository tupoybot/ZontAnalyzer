# Отчёты, аптайм и восстановление синхронизации

Доработка этапа 9; развёрнута, [PR #7](https://github.com/tupoybot/ZontAnalyzer/pull/7)
ожидает приёмки владельца.

## Исправленные причины

- Недельный отчёт за 14–20 сентября был рассчитан, но ожидал публикации за
  обновлениями старого архива. После последнего дневного отчёта очередь сначала
  публикует новые отчёты, начиная с самых свежих. Лимит восемь за цикл сохранён.
- Разрыв телеметрии ошибочно становился новым началом аптайма обоих устройств.
  Пропуск данных сам по себе не доказывает перезапуск. Якорь сохраняется;
  непрерывность при пропусках отмечается как неподтверждённая. Проверка свежести,
  офлайн-состояние и исключение ненаблюдаемых интервалов из MTBF/MTTR сохраняются.
- Дешевизна кандидата больше не достаточна для рекомендации сменить модель.
  Нужны сопоставимые оценки фактов, советов и неопределённости на пакетах
  приложения, без ухудшения ни по одному измерению. Отсутствующая оценка не
  считается нулевой или успешной. Подробности: [политика](./model-maintenance-plan.md)
  и [оценочные пакеты](./model-evaluation.md).

## Синхронизация

Окно перекрытия по умолчанию — 120 минут для телеметрии и событий. После ошибки
истории или событий их курсор остаётся на последней успешной записи. Следующий
цикл догружает весь пропущенный интервал с перекрытием; двухчасовое окно не
ограничивает длительность восстанавливаемого простоя. Канонические ключи и UPSERT
не дают повторным запросам создавать дубли. Явный backfill перечитывает события
за запрошенный период, даже если обычный курсор уже ушёл вперёд.

Это защита от ошибок запросов и задержек до двух часов. Если API отвечает успехом,
но скрывает данные дольше окна, их можно восстановить явным backfill; отдельный
периодический полный пересмотр истории не добавлялся.

## Проверка и перенос в cloud-first

На онлайн-копии БД проверены дневные отчёты за 19 и 20 сентября и неделя 14–20
сентября. Исправление аптайма сохраняет исходные AI-тексты и рекомендации.
Сверка с API за 18–20 сентября не выявила потерянных событий надёжности;
десятиминутный промежуток в напряжении присутствует и в архиве ZONT. Нефильтрованный
журнал за этот интервал содержит две смены целевой температуры, а не перезапуск.

Локально: 683 теста, Ruff, mypy и сборка wheel/sdist прошли в Docker. Два одинаковых
запроса синхронизации с двухчасовым перекрытием завершились успешно; число строк
телеметрии после повторения не изменилось. Подготовлен и проверен повторяемый
точечный ремонт трёх сохранённых отчётов, без пересчёта на сервере и новых AI-вызовов.
Реальные сравнительные AI-ответы в рамках этой доработки не генерировались;
измеренные оценки качества не подменяются синтетическими тестовыми баллами.
