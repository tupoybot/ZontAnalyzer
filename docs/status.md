## Активные контракты 9.1

- Цена/валюта меняются рядом с показанием газа. Обычное изменение — со следующего
  календарного месяца; последнее сохранение планового месяца действует, прежние
  значения остаются в аудите. Исторические месяцы можно внести явно.
- Стоимость рядом с общим объёмом, без подписи «оценка». При нехватке места число
  с единицами переносится целиком; надёжность в скобках после «Расход газа».
  Легенда распределения на дашборде — без денег; подробные метрики содержат известные
  суммы. Неизвестная стоимость не добавляет подпись и разделитель рядом с объёмом.
  Валюты не конвертируются; выводы об эффективности не зависят от смены цены.
- Числовые поля принимают точку и запятую, ошибочный ввод не очищает данные.
  Проверка показания видит текущий паспортный максимум; дата применимости
  по-прежнему ограничивает сравнение прошлых показаний.
- Заголовок недневных отчётов содержит обе даты, дневного — одну.
- Автоматический пересчёт после обновления данных показывает причину сохранения
  AI-ответа и его исходное время. Повторные пересчёты не сдвигают это время.
  Неудачное обновление AI и обновление только расчёта газа объясняются отдельно.
- Часовые пояса отображаются по словарю ZONT (например, `UTC+4 — Самара, Удмуртия`);
  идентификаторы для вычислений сохраняются. В пользовательской прозе технические
  имена заменены понятными описаниями; исходные AI-ответы, JSON и ссылки на свидетельства сохраняются.
- Корневой README актуализирован: возможности, месячные тарифы, веб-формы,
  команды публикации и статус каналов доставки.
