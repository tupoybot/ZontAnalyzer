## Подготовленный хотфикс

Кандидат `00c50d8`, образ
`sha256:a3ad3b1e2d378dfcd1f7ce2cf9c32fdeee05a9a8108917cf743c26e5dd59477d`:
[понятные объяснения и сезонное сравнение](./reports/thermal-observations.md#текущий-контракт-отчёта).
Наблюдения раскрыты перед техническими подробностями, сравнение сезонов — сразу
после сводки. `analyst-v8.7` предназначен для новых AI-анализов; старые тексты
сохраняются. Оформление архива обновляется порциями без повторного AI и пересчёта газа.
В проверенном сезонном отчёте нет сопоставимых пар суток: новый блок показывает
причины отсутствия сравнения, а не придумывает численные выводы.

Прошли 1120 тестов, Ruff/mypy, сборка, браузерные сценарии на телефоне и компьютере,
проверка пяти сохранённых отчётов и точного опубликованного образа.
[CI и сборка образа](https://github.com/tupoybot/ZontAnalyzer/actions/runs/40009909391),
[проверки PR](https://github.com/tupoybot/ZontAnalyzer/actions/runs/40009916318) успешны.
Один пробный AI-ответ проверен; последующее уточнение приоритета сезонного сравнения
не проверялось вторым запросом.

Выпуск заблокирован сбоем Яндекса: Logging API и создание ревизии возвращают 503.
Terraform сообщил об успешном применении, но предупредил о неудаче создания ревизии;
прямая проверка подтвердила, что работает прежний образ. Повтор через API также
получил 503. Перед следующей попыткой необходимы обновление состояния Terraform
по рабочей среде и новый просмотр плана; сохранённый план повторно не применять.
Резервная копия YDB готова. Хотфикс пока не работает в production.

## Что остаётся и следующий результат

- PR #62 не принят владельцем и не слит. После восстановления API нужно выпустить
  хотфикс и подтвердить работу точного образа короткой проверкой.
- По #69 остаётся наблюдение за продолжением длинного AI-анализа и явная приёмка.
  Расчёт фактов должен укладываться в один запуск; исчерпание ответа AI — #73.
- Суммарная экономия RU не доказана. Следующая очередь: стенд RU/сек (#70),
  оптимизация (#64), правила пересчёта (#58), дорогой monitoring (#65).
  Новые задачи не запущены.

  Её публикация и окончательная приёмка М6 остаются отдельной работой (#72, #17).
- Многокомнатность и управление отложены. Остальные задачи и зависимости —
  в [плане](./implementation_plan.md) и Project.
