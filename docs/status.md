## Старый production

До М8 работает отдельный SQLite-выпуск из `old-stable`; облачные образы на него
не устанавливаются. Приложение только читает ZONT.

Commit `4707a9e`, тег `release-9-report-highlights-gas-20260921-r2`;
образ `ghcr.io/tupoybot/zontanalyzer@sha256:58b0d4d36f853bfe2ce0a851330510e830c3994b5342cf86447c7c1782c10f71`.
Миграция `f1a2b3c4d5e6`. Последняя зафиксированная проверка: worker healthy,
HTTP heartbeat 200, внешний Basic Auth 401; локально прошли 723 теста,
Ruff/mypy, сборка и проверка на отдельной записываемой онлайн-копии БД.
Это свидетельства выпуска, а не текущая проверка сервера.

Действуют [синхронизация и восстановление](./reports/report-sync-reliability.md),
[инкрементальная публикация](./reports/incremental-publication.md),
[значимые события и диаграммы газа](./reports/report-highlights-gas.md).
Период опроса — 30 минут, перекрытие — 120 минут; дневной отчёт ждёт 60 минут
после местной полуночи. Пересчёт сохраняет AI; очереди переживают перезапуск.
Контракты газа, моделей и остальных функций доступны через карту документов.
