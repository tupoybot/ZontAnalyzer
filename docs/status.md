  применяются в следующем анализе; исторические AI-ответы не подменяются.

  В проверенном снимке: по воздуху с ПИД, P=10/I=1, ПЗА ограничивает расчётную
  температуру; семь точек совпали с интерфейсом производителя.

  Последний дневной отчёт имеет приоритет; массовые изменения обновляются пакетами.

## Cloud-first M0 — подготовлен к приёмке

- [Контракты и проверки M0](./cloud_first_m0.md), ветка `docs/cloud-first-m0`.
  Владелец выбрал получение телеметрии при генерации отчёта, без отдельного
  пятиминутного сборщика. OpenAI направляется через Xray-клиент рядом с приложением
  и внешний egress; ZONT — напрямую. Прикладной маршрутизации достаточно,
  сетевая изоляция произвольного кода не требуется.
- Подтверждены read-only доступ к выбранному cloud, активный billing и свободные
  квоты Containers/YDB. Полная сценарная смета сверена с приватным ориентиром
  только для Yandex Cloud; фактическое потребление проверяется в M1–M3.
- Подготовлены карта данных/web API, storage/publisher/jobs/secrets контракты.
  Выбран отдельный тестовый поддомен с внешним DNS; адрес хранится приватно.
  DNS-записи вносит владелец вручную по подготовленным значениям.
  Интерфейс egress выбран, параметры найдены в приватной конфигурации;
  совместный запуск приложения/Xray проверяется в M1. Выбраны независимый
  S3/SSE-KMS state с versioning/lockfile и отдельные bootstrap/deploy identities.
  Подтверждение условий доступа к AI получено со слов владельца; ответ провайдера
  независимо не проверялся. Эксплуатационный контракт egress определён;
  IAM/backend/runtime smoke остаётся в M1–M2.
- Документы/ссылки/diff/privacy проверены, application совпадает с `origin/main`
  (`82a7a82`). [PR M0](https://github.com/tupoybot/ZontAnalyzer/pull/4) ожидает приёмки
  и merge в `architecture/cloud-first-serverless`. M1 не начат;
  application/production и облачные ресурсы проекта не менялись.
