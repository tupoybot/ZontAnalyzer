  Сбор, пересчёт и публикация используют общую блокировку в YDB, история читается
  потоком, перед новым AI-запросом проверяется запас времени.
  Развёрнут хотфикс `0a7cde3`: фоновые вызовы проверяют подготовленную схему
  без повторной инициализации. Просроченные рекомендации обслуживаются раз в час,
  снимок мониторинга выполняет отдельный часовой таймер. Температуры и исходные
  события внутри газовой калибровки обновляют только зависимые периоды; состояния
  котла и модуляция сохраняют обновление архива. Старые задания публикации не удалены.
  Прошли 1018 локальных тестов (609 без YDB и 409 с YDB), Ruff/mypy, сборка и CI.
  Опубликованный неизменяемый образ проверен локально и развёрнут с сохранением
  содержимого. Облачные проверки авторизации, готовности и обе служебные пробы
  аналитики прошли; журнал подтвердил успешные scheduler и maintenance новой версии.
  Открытие рабочей схемы проверено двумя чтениями без записи. Перед выпуском
  создана штатная резервная копия рабочей YDB; через API подтверждено состояние Ready.

  сохранены. Все 14 правил мониторинга включены. Владелец подтвердил перенос
  обновлённого приватного `M1_CONFIG_JSON` в GitHub Environment.
  Очередь публикации остаётся непустой; короткая проверка не доказывает её устойчивое
  завершение после полного цикла сбора при 100 RU/с. Остаются выборочная проверка
  такого цикла, согласование статуса «Готово» с публикацией HTML и отдельная
  очистка временных ресурсов. Эти действия сохранены как последующая работа;
  приёмка не означает, что непроверенные свойства уже подтверждены.
  Сокращение избыточного хранения вынесено в отложенный техдолг
  [М8-1, задача #57](https://github.com/tupoybot/ZontAnalyzer/issues/57), не блокирует
  перенос и этим хотфиксом не начинается.

## Старый production

После приёмки М8 старое приложение полностью выключено: контейнер остановлен,
его автоматический перезапуск отключён, прежние маршруты сайта и API возвращают
HTTP 503. Проверены настройки nginx и неизменность соседнего сайта; nginx и
соседний транспортный сервис работают. Контейнер, данные, отчёты, конфигурация
и исходные настройки маршрутов сохранены по указанию владельца.
Облачные образы на старую систему не устанавливаются. После открытия облачных записей
простое включение старого worker не является актуальным восстановлением.

Commit `4707a9e`, тег `release-9-report-highlights-gas-20260921-r2`;
образ `ghcr.io/tupoybot/zontanalyzer@sha256:58b0d4d36f853bfe2ce0a851330510e830c3994b5342cf86447c7c1782c10f71`.
Миграция `f1a2b3c4d5e6`. Последняя зафиксированная проверка: worker healthy,
HTTP heartbeat 200, внешний Basic Auth 401; локально прошли 723 теста,
Ruff/mypy, сборка и проверка на отдельной записываемой онлайн-копии БД.
Это свидетельства выпуска, а не текущая проверка сервера.

Действуют [синхронизация и восстановление](./reports/report-sync-reliability.md),
[инкрементальная публикация](./reports/incremental-publication.md),
[значимые события и диаграммы газа](./reports/report-highlights-gas.md).
Период опроса — 30 минут, перекрытие — 120 минут; дневной отчёт ждёт 60 минут
после местной полуночи. Пересчёт сохраняет AI; очереди переживают перезапуск.
Контракты газа, моделей и остальных функций доступны через карту документов.
