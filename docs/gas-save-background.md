# Быстрое сохранение показания газа

Статус: реализуется в `stage9/gas-save-background`, приёмка владельца впереди.

## Причина и контракт

10 сентября 2026 два PUT показания 1929 м³ за 9 сентября получили HTTP 504:
запись уже была сохранена, но обработчик ждал полной публикации архива.
Браузер пытался разобрать HTML ошибки как JSON. Повтор не создал дубль.

Газовый PUT теперь подтверждает durable-запись без публикации и без ожидания
`.publication.lock`. Ответ содержит актуальные показание, историю и проверку
правдоподобия; форма сразу обновляется. Сохранение, исправление, повтор и удаление
имеют одинаковый контракт. Ошибки HTTP без JSON отображаются понятным сообщением.

HTML и газовая аналитика обновляются существующим worker в ближайшем успешном
цикле. Полный проход остаётся нужен для калибровки и сравнений, затрагивающих другие
периоды, но отдельный проход на каждый PUT больше не запускается. Новые потоки,
очереди и миграции не нужны: каждый цикл читает актуальное состояние БД. После
перезапуска или ошибки публикации следующий успешный цикл подхватывает изменения;
при ошибке синхронизации обновление HTML также задерживается. Форма после reload
читает показание через GET и не зависит от возраста HTML.

Публикация сохраняет существующую блокировку писателей и защиту новых версий.
Профиль, тарифы и комментарии в этой доработке не меняют порядок публикации.

## Проверка

Регрессионный HTTP-тест держит блокировку публикации и проверяет быстрые запись,
повтор, исправление и удаление. Затем новый runtime имитирует перезапуск и ошибку
публикации: повторный проход публикует последнее значение без потери записи.
Клиентские проверки покрывают HTML 504, JSON-ошибку и успешные операции.

Доказательства выпуска будут добавлены после локальной проверки и deployment.
