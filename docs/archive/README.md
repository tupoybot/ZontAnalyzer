# Архив документации

Не читать при обычном старте задачи и не включать в массовые поиски.
Открывать только по острой необходимости: конкретный вопрос об историческом
контракте, доказательстве проверки или прежнем решении, который не решается
актуальными документами и кодом. Читать один нужный файл/раздел.

Снимок [pre-operation](./pre-operation/) сохранён перед введением этапа 9
(2026-09-07). Записи внутри отражают моменты времени, могут противоречить друг
другу и **не определяют текущую готовность или порядок работ**.
