# Как показания счётчика влияют на отчёты

`#for-human`

## Сохранение показания

Форма подтверждает запись, исправление или удаление сразу после сохранения данных.
Повтор той же записи сохраняет единственный экземпляр в истории. После обновления
страницы форма читает актуальную историю счётчика.

В [#124](https://github.com/tupoybot/ZontAnalyzer/issues/124) изменён порядок
применения калибровки. Дневной отчёт сохраняет оценку объёма газа, доступную в
момент анализа. Следующий расчёт может использовать новое показание. Открытие
архива, обновление формы и фоновая публикация сохраняют прежние оценки.
Исправление ошибочного показания учитывается в будущих расчётах. Историческая
оценка может поэтому расходиться с уточнёнными данными счётчика.

## Неделя, месяц и сезон

Для нового сводного отчёта приложение складывает оценки из сохранённых дневных
отчётов в часовом поясе периода. У текущего сезона расчёт заканчивается последним
включённым днём. Известный нулевой расход входит в сумму как ноль. Если часть
дней отсутствует, отчёт показывает объём за дни с оценкой и их количество.
Разные версии калибровки допустимы. Если менялся охват измерения, объёмы для
котла и для общего счётчика показываются отдельно.

Сумма дневных оценок может отличаться от разницы двух показаний счётчика.
В сводке видны дни, из которых получился итог. Приложению больше не нужно
заново читать исходную телеметрию этих дней для вычисления объёма газа.

При неполных данных известные кубометры видны и без доли в процентах.
Доля требует общего объёма за те же дни. Если сравниваются котёл и общий
счётчик, отчёт показывает стоимость каждого периода отдельно.

При исправлении тарифа сохраняется исходный объём архивного отчёта.
Для границы между месяцами приложение использует сохранённые части объёма.
Если новой границы в них ещё нет, расчёт может восстановить пропорции по
сохранённой модели того же расхода. При недостаточных данных стоимость
остаётся неизвестной. Повторный пересчёт использует уже сохранённые части.

## Проверка

Сохранить дневной отчёт, внести показание на изолированной копии и дождаться
завершения публикации. Сравнить газовые данные архивных отчётов до и после записи.
Для нового периода независимо сложить объёмы дневных отчётов и проверить сумму,
число известных дней и пропуски. Методику измерения нагрузки описывает
[проверка расходов YDB](../development/ydb-cost-acceptance.md).
