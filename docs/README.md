[Архив](./archive/README.md) содержит историю и старые проектные решения.
Открывать его только для конкретного исторического вопроса, который не решается
актуальными документами и кодом; архив не определяет текущий статус или план.

Цель продукта, действующие архитектурные решения, политика выбора моделей, потоки
данных и ещё нужные планы интеграций должны оставаться в актуальных документах.
Наличие реализации в коде не заменяет описание причин и намерений. Экономия контекста
достигается чтением нужных разделов, а не переносом действующего замысла в архив.
