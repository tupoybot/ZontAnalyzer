## Контракт

Суточный отчёт после полуночи относится к завершённому предыдущему дню в часовом
поясе объекта. Само повторное формирование отчёта не доказывает изменение фактов.
Повторный автоматический расчёт сохраняет исходное пояснение AI без нового запроса.

Контрольная сумма `facts-v2` исключает происхождение ответа AI и время повторного
получения тех же настроек/координат. Значения настроек, показатели, события и
содержательный контекст остаются частью сравнения. Отчёт не включается в собственную
историю дома; исключение выполняется до ограничения числа исторических дней.

Для старой контрольной суммы совпадение проверяется по прежнему алгоритму с
исходными сведениями об AI. Только доказанное совпадение позволяет перейти на
новую контрольную сумму. Несовпадение старого формата означает неопределённость:
он включал служебные поля, поэтому не доказывает изменение показателей.
Существующие предупреждения этого формата отображаются с этим ограничением без
перезаписи сохранённого AI-ответа. В HTML предупреждение выводится один раз,
перед пояснением AI.

## Проверка

- Регрессии: одинаковый завершённый день до/после сохранения, служебные поля AI,
  повторный опрос настроек, действительное изменение расхода/настроек, старый формат.
- На online-копии отчёта за 2026-09-08 обнаружено включение его самого в историю.
  Повторный расчёт на devbox сохранил все 42 метрики и исходный AI-текст; отличались
  история дома и служебные времена получения настроек/местоположения.
- Исходные данные AI в 00:02 полностью не сохранены; равенство им не заявляется.
  Для этой диагностической версии остаётся ограничение точности исторического сравнения.
- Реальных запросов OpenAI: 0. Приёмка и сборка выполняются в Docker на devbox.
