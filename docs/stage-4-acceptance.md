# Этап 4 — техническая приёмка

Дата: 2026-09-06. Ветка `stage4`, от актуального принятого `main` (`3670959`).
Статус: реализация, технические проверки и deployment завершены; ожидает приёмки владельца.
Слияние и закрытие этапа ожидают явной приёмки владельца.

## Реализовано

- Строгий API DTO → доменные Pydantic-модели → canonical JSON без миграции БД.
  Необязательные наблюдения, конкурирующие гипотезы с интервалом/основаниями/свидетельствами
  за и против, прогнозы с допущениями/проверкой, unknown и один ручной эксперимент.
- HTML/text различают наблюдение, расчёт, гипотезу и прогноз; уверенность модели
  не является калиброванной вероятностью. Неизвестная ссылка сохраняется и помечается
  неподтверждённой, включая прежние рекомендации. Исторические источники имеют ID,
  интервалы и доступные значения; прежняя гипотеза не становится свидетельством.
- Prompt `analyst-v4`: контекст ГВС/AutoAdapt, потребление и автоматика как альтернативы,
  присутствие только как косвенная гипотеза, приоритет владельца, полезное отсутствие совета,
  осторожность с дополнительными датчиками и неизвестной совместимостью, сохранение
  семантики надёжности и шума. Модель и reasoning effort не менялись; `store=False`,
  инструменты отсутствуют, месячный бюджет сохранён. Выход ограничен 6000 токенами
  для расширенной схемы. Журнал фиксирует фактическую версию prompt независимо от старого config.
- Ограниченная история: до 7 предыдущих неперекрывающихся дневных отчётов; компактные
  профили ГВС/интерпретации/шум из последних 3. Число выбранных эпизодов ограничено и
  обозначено; прошивка остаётся unknown, пока нет проверенного исторического источника.
  Временные окна имеют отдельный бюджет 16 KiB, чтобы контекст не выпадал из пакета.
- Worker сохраняет новые поля при штатном AI reuse и при ошибке refresh.
  Старые отчёты совместимы; существующий lifecycle feedback сохранён.
- Вид газа — выпадающий список: не указано, природный газ (метан), сжиженный
  пропан-бутан, пропан, бутан. Неизвестное прежнее значение сохраняется без перезаписи.
