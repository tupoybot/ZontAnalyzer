# Этап 4 — техническая приёмка

Дата: 2026-09-06. Ветка `stage4`, от актуального принятого `main` (`3670959`).
Статус: реализация и локальная приёмка завершены; release/deployment выполняются.
Слияние и закрытие этапа ожидают явной приёмки владельца.

## Реализовано

- Строгий API DTO → доменные Pydantic-модели → canonical JSON без миграции БД.
  Необязательные наблюдения, конкурирующие гипотезы с интервалом/основаниями/свидетельствами
  за и против, прогнозы с допущениями/проверкой, unknown и один ручной эксперимент.
- HTML/text различают наблюдение, расчёт, гипотезу и прогноз; уверенность модели
  не является калиброванной вероятностью. Неизвестная ссылка сохраняется и помечается
  неподтверждённой, включая прежние рекомендации. Исторические источники имеют ID,
  интервалы и доступные значения; прежняя гипотеза не становится свидетельством.
- Prompt `analyst-v4`: контекст ГВС/AutoAdapt, потребление и автоматика как альтернативы,
  присутствие только как косвенная гипотеза, приоритет владельца, полезное отсутствие совета,
  осторожность с дополнительными датчиками и неизвестной совместимостью, сохранение
  семантики надёжности и шума. Модель и reasoning effort не менялись; `store=False`,
  инструменты отсутствуют, месячный бюджет сохранён. Выход ограничен 6000 токенами
  для расширенной схемы. Журнал фиксирует фактическую версию prompt независимо от старого config.
- Ограниченная история: до 7 предыдущих неперекрывающихся дневных отчётов; компактные
  профили ГВС/интерпретации/шум из последних 3. Число выбранных эпизодов ограничено и
  обозначено; прошивка остаётся unknown, пока нет проверенного исторического источника.
  Временные окна имеют отдельный бюджет 16 KiB, чтобы контекст не выпадал из пакета.
- Worker сохраняет новые поля при штатном AI reuse и при ошибке refresh.
  Старые отчёты совместимы; существующий lifecycle feedback сохранён.
- Вид газа — выпадающий список: не указано, природный газ (метан), сжиженный
  пропан-бутан, пропан, бутан. Неизвестное прежнее значение сохраняется без перезаписи.

## Проверки и ограничения

- 210 локальных тестов без HTTP и 3 HTTP-теста; Ruff/mypy, sdist/wheel прошли.
- Локальный Docker image, Docker HTTP test, Compose, nginx Basic Auth и Chromium
  прошли. Браузер проверил reasoning/XSS, выбор газа, reload, legacy gas и ширину 390 px.
- Mock-регрессии: конкурирующие гипотезы, unknown, прогнозы, неизвестные ссылки,
  запись/чтение SQLite, legacy reports, reuse/failure, точечные интервалы, XSS,
  временные/исторические источники, strict JSON schema и ограничения вызова API.
- [Оценочный набор](./stage-4-evaluation.md): 12 разнообразных сценариев с рубриками.
  Проверена пригодность всех входов; семантический прогон всех кейсов моделью не заявляется.
- Один синтетический OpenAI-запрос обнаружил ошибку валидации нулевого интервала;
  исправление проверено mock-регрессией, повторного вызова нет. Production payload
  не отправлен: запрос отклонён автоматической проверкой разрешений до выполнения.
- Штатный online backup HK: `/opt/zont-analyzer/data/backups/zont-analyzer-20260906T155135345650Z.sqlite3`.
  Локальный исходник `/tmp/zont-stage4/source/production.sqlite3`, отдельная writable-копия
  `/tmp/zont-stage4/data`, изолированная публикация `/tmp/zont-stage4/publish`.
- Реальный день 2026-09-05: качество 0.9061, пакет 59682 байта; присутствуют ГВС,
  история, профиль, надёжность и sensors. Удалённые из пакета элементы учтены явно.
  Integrity/FK OK. HTML/JSON/text проверены локально без AI. Архив публикуется из
  другой копии исходной БД с сохранением существующих AI-выводов и всех данных владельца.
- Дополнительная модель газа и выполнение структурированных экспериментов остаются
  последующими этапами. Новые поля AI заполняются при последующих штатных анализах;
  синтетические данные или выводы в production не публикуются.

Локальная Docker-приёмка без сети опубликовала 124 архивных отчёта. Полностью
сохранены 13 записей профиля, 4 показания и 4 audit, 14 interventions,
150 рекомендаций, 25 llm_calls, 130 canonical reports. Integrity/FK OK.
