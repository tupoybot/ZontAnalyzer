# Локальная проверка в Docker

Для ветки М4 используйте `deploy/check-local.sh` из корня репозитория. Скрипт
собирает Dockerfile stage `test`, запускает Ruff и mypy, затем через
`deploy/check-ydb.sh` выполняет **весь** pytest на одноразовой локальной YDB и
собирает wheel/sdist. Доступ к ZONT и OpenAI для этих проверок не нужен. Это
локальные технические проверки кандидата, а не приёмка М4 или развёртывание.

```sh
deploy/check-local.sh
```

Доступны отдельные операции:

```sh
deploy/check-local.sh build
deploy/check-local.sh check
deploy/check-local.sh export --out-dir /absolute/path/to/artifacts
deploy/check-local.sh all --out-dir /absolute/path/to/artifacts
```

`check` тоже собирает актуальный test-образ перед проверками. `export` сохраняет
пакеты только в явно заданный абсолютный каталог вне репозитория. Без `--out-dir`
сборка пакета остаётся во временном каталоге контейнера.

`check-ydb.sh` создаёт отдельную Docker-сеть и временный контейнер YDB,
дожидается доступности сервиса, передаёт тестам `YDB_TEST_ENDPOINT`, выполняет
весь набор тестов и проверяет установленный CLI командой `init` на чистой схеме.
При завершении скрипт удаляет созданный стенд. Исходный репозиторий монтируется
только для чтения; временные файлы лежат в контейнерном `tmpfs`. Внешние API
не вызываются. Запуск pytest без `YDB_TEST_ENDPOINT` не заменяет этот проход:
часть проверок хранилища будет пропущена.

Python и pip на хосте для этого процесса не нужны. Не устанавливайте зависимости
в host Python или локальную `.venv`. Для задачи Codex Cloud без Docker используйте
`deploy/check-codex-cloud.sh`; его проверки с фикстурами не заменяют Docker/CI,
проверку неизменяемого образа и отдельную приёмку на данных.

Кандидат М4 хранит рабочие данные в YDB. Локальные каталоги данных и публикации
нужны для временных файлов, HTML/JSON и статуса фонового процесса; они не являются
копией базы. Работающий прежний выпуск остаётся на ветке `old-stable` до этапа М8.
Его SQLite-команды и порядок эксплуатации приведены в
[README прежнего выпуска](https://github.com/tupoybot/ZontAnalyzer/blob/old-stable/README.md).
