## Проверка сохранности и восстановление

До удаления создан приватный архив Git (`bundle`) и проверено его восстановление
в отдельный репозиторий: совпали все 51 исходная ссылка, доступны семь коммитов
рабочих каталогов и оба stash. Архив хранит также уникальные коммиты старых docs-веток.
Он не предназначен для публикации: включает приватную резервную историю.

Все шесть удалённых каталогов проверены непосредственно перед действием:
незакоммиченной работы и активных пользователей каталогов не было.
458 игнорируемых файлов браузерных зависимостей отдельно сохранены в приватный
архив; остальные каталоги не содержали игнорируемых файлов. Удаление не затронуло
приватную конфигурацию и данные основного каталога.

Для восстановления нужной ветки используйте исходный ref и SHA из приватного
перечня, сначала в отдельном каталоге:

```sh
git clone --mirror "$ZONT_RECOVERY_BUNDLE" "$ZONT_RECOVERY_DIRECTORY"
git -C "$ZONT_RECOVERY_DIRECTORY" rev-parse refs/heads/BRANCH
```

Для ветки, которая существовала только в origin, исходная ссылка в архиве имеет
вид `refs/remotes/origin/BRANCH`. Сверьте полученный SHA с перечнем до переноса
коммитов в рабочий репозиторий. Восстановление не требует публикации архива целиком.
История общих веток не переписывалась; защищённые указатели не перемещались.
