## Issue body

## Проблема

Полный Terraform plan останавливается с `Unavailable` при чтении существующей группы Cloud Logging. Доступ к хранилищу состояния и работа приложения проверены. Журналирование приложения, диагностического контейнера и API Gateway временно отключено через `cloud_logging_enabled=false`; группа и прежние журналы сохранены. Отключение записи не устраняет зависимость Terraform от API чтения группы.

## Результат и приёмка

- Установить причину ошибки чтения и получить свежий полный plan с действующим удалённым состоянием.
- Сверить ревизии приложения и диагностического контейнера, настройки шлюза, отключённое журналирование, ограничения ресурсов и политику версий Object Storage с фактическим состоянием.
- Сохранить группу и прежние журналы; не обходить ошибку удалением ресурса из state или непроверенным применением старого плана.
- Если понадобится изменение Terraform, проверить режимы включённого и отключённого журналирования. Возобновление записи выполнять отдельным явным решением.
- Не публиковать состояние, планы, идентификаторы окружения и журналы с приватными данными.
